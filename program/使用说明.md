# 护角、盖板与平板生成器 v1.5.0

## 独立 EXE（推荐）

从仓库 Releases 下载 CoverGenerator.exe，双击运行即可。内置 Python、Tk 和建模依赖，无需手动安装，也不需要首次联网。单文件运行时会先解压内部运行库。

## 源码启动

安装 Windows 64 位 Python 3.13 或 3.14，保留 Tcl/Tk 并勾选 PATH。
双击“启动生成器.cmd”，首次会创建独立环境并联网安装 requirements.txt 中的固定版本。后续检查通过后直接打开窗口。安装失败可重新启动重试。“安装依赖.cmd”仅准备环境，不启动窗口。

## 操作

1. 在左侧选择七种模型之一。
2. 修改尺寸（毫米）。参数合法时右侧自动更新实际网格，拖动旋转、滚轮缩放。
3. 选择输出目录并点击“生成模型”，等待封闭性和尺寸检查完成。
4. 点击“打开文件夹”查看 STL、SCAD、HTML、参数记录和打印说明；“打开 3D 预览”可打开独立离线 HTML。
5. 点击“版本更新”阅读当前及历史版本说明；点击模型或返回按钮回到工作台。

设置保存在 %LOCALAPPDATA%/CoverGenerator/settings.json，包含各类型参数和输出位置。恢复默认只作用于当前类型。每次生成新建带时间戳的文件夹。

## 构建

双击“打包EXE.cmd”，构建环境与运行环境分离；输出在 dist/CoverGenerator.exe。打包需要联网安装构建依赖，最终 EXE 离线运行。

模型尺寸含义和打印注意事项详见仓库 README。请先切片检查并打印试配。
