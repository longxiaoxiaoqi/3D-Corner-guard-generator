# 护角与 U 形盖板生成器 v1.2

新增 **U 形盖板** 选项卡：输入内宽、长度、侧壁内高、平板厚度和侧壁厚度（默认 100、120、15、3、3 mm）。
模型是一块平板加两条相对侧壁，长度方向两端开口；外形尺寸为长度 ×（内宽＋2×侧壁厚）×（侧壁内高＋平板厚）。
净尺寸不额外增加装配间隙。两条侧壁等高等厚，输出单件盖板 STL、参数化源文件、离线预览及说明。

```powershell
python corner_guard.py --type ucover --width 100 --length 120 --height 15 --base 3 --wall 3 --out ./ucover-model
```

平板外表面朝下打印，并确认模型尺寸适合打印平台。

另外保留两种护角类型：

- **PCB 夹槽护角**：使用内嵌深度、夹槽、上下垫高、边长和壁厚，保持原版功能。
- **立方体 / 长方体三面护角**：围住顶点相邻的三个面，其他方向敞开；输入 X/Y/Z 包覆长度和壁厚。

三面护角默认三个包覆长度各 20 mm，壁厚 3 mm。长度不含壁厚，不是物体完整长宽高，三方向可以不同。
三面模式输出单件、镜像件与八件排版（四个原件、四个镜像件）。异长三方向可通过镜像与旋转匹配八个角。

```powershell
python corner_guard.py --type cuboid --x 20 --y 25 --z 30 --wall 3 --out ./cuboid-model
```

三面模式不使用 PCB 夹槽、内嵌深度或上下垫高参数。每条棱两端的包覆长度之和不能超过物体对应尺寸。

## 窗口使用

首次使用请先安装 Python 并运行“安装依赖.cmd”。依赖准备好后，双击“启动生成器.cmd”，填写尺寸，点击“生成护角模型”。
完成后可点击“打开 3D 预览”拖动查看模型。每次生成均新建时间文件夹，保留此前结果。

默认值：内嵌 2.2 mm、夹槽 4.1 mm、上垫高 5 mm、下垫高 5 mm、护角边长 15 mm、外侧壁厚 3 mm。
边长是护角沿 PCB 每条边的延伸长度，不含外侧壁厚。例如边长 15、壁厚 3，单件外形宽度为 18 mm。
夹槽是实际槽高，不会再自动增加公差。上下垫高可以不同。

每次输出：单件 STL、对应类型的排版 STL、可修改的 OpenSCAD 文件、可离线旋转的 HTML 预览、参数与检查记录、打印说明。
STL 单位按毫米使用。无需安装 OpenSCAD 即可生成 STL。

## 其他电脑

这是 Python 程序包，不是独立 EXE。当前在 Windows / Python 3.14 验证。
其他电脑先安装含 tkinter 的 Python 3.14 并加入 PATH，解压整个文件夹，然后运行“安装依赖.cmd”；此步骤需要联网。
之后生成模型和查看预览均可离线运行。

## 命令行

```powershell
python corner_guard.py --overlap 2.2 --slot 4.1 --top 5 --bottom 5 --arm 15 --wall 3 --out ./my-model
```

命令行输出到指定目录；该目录内的同名模型文件会更新。需要保留旧版本时，使用新的目录。
所有尺寸须为 0.2～1000 mm 的有限数值；PCB 模式的护角边长必须大于内嵌深度。这只是程序输入范围，不表示每个极端组合都适合打印。

## 适用范围

PCB 模式用于 L 形上下加厚开槽护角，四个角共用同一模型。PCB 长宽不影响护角形状，因此无需重复输入。
原 PCB 允许接触的边缘带为 3 mm；新参数和新 PCB 都应核实接触区域。
没有主动锁扣，运输时用包装定位；先打印单个试配。生成器验证网格和尺寸，不替代实物测试。
